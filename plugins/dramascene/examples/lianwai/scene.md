# 《帘外》· 现代对白与灵活镜头版

案例版本：2.0.0；模块版本：1.0.0。此稿替代旧案例的对白、固定动作和静物优先镜头，不改原词文本。

## 创意意图

同一雨后庭室中，两人自然交谈：花还在，但是否已经少了些？平和关切，不演郁闷。

整首词的风雨残迹、酒意、帘、人、海棠和观看差异存在于一个雨后庭室。人物自然交谈与移动；过去由眼下的对白与残迹承载，不另拍夜雨、饮酒、入睡或醒来。原诗用字幕提示，演员不念原诗。

## 空间与状态

室内小几与椅子—帘口—近庭同一株海棠。帘内人可正常起身走到帘内侧；边框仍遮住花叶细节。卷帘人可以调整帘高、转向同伴，但不开成无遮拦的全景。

人物沿用帘内人、卷帘人，不擅自补姓名、确切身份或作者生平。服装与庭室延续原设定，语言改为当代普通话。帘内人从已清醒、正常坐姿开始；未散酒意由对白交代，不靠眼睑下垂、摇晃或低头来表达。

## 场景文学稿

S1　内连外　庭室／帘口／近庭　日·雨后

帘外同一株海棠叶密花疏，有完整的花，也有贴在湿石上的少量既有落瓣。小几上有酒盏。卷帘人整理帘子，帘内人放好杯子，正常转身看她。

帘内人：你帮我看看，外头那棵海棠怎么样了？

卷帘人调整帘卷，转向同伴。

卷帘人：我看着跟原来差不多，花还开着呢。

帘内人把椅子向内收好，正常起身，走两步到帘内侧。边框还挡着花叶细节。

帘内人：昨晚雨下得稀稀落落的，风倒挺急。我睡得那么沉，酒劲儿还是没过去。

帘内人看着同伴，稍扬眉，语气平和。

帘内人：你仔细看了吗？真跟原来一样？

她用一个自然手势指向庭院，不走出去查看。

帘内人：我估计，叶子应该更茂盛了，花倒少了些。

卷帘人把帘绳放稳，两人自然调整站位。花叶仍是同一状态，没有新增落花，也没有人宣布已经核验。

镜头时长仅供试拍参考，不能当作已完成视频或准确朗读用时。对白段不让声音悬在花枝上；需要短暂听者反应可插入，但回到当前说话者。人物看同伴，不直接看摄影机。

## 旁白与诗句字幕

旁白只在对白空隙使用。可按剪辑需要选用两句，不与人物抢声：

N1：她问的是花有没有变化，不只是花还在不在。

N2：这里的“应该”，还带着猜测。

| 诗句提示 | 对应语义与出字时机 |
|---|---|
| 昨夜雨疏风骤 | 过去一夜雨疏风急；不重演夜景；对应对白结束后的同场空隙提示 |
| 浓睡不消残酒 | 深睡后酒意仍在；不是只指杯中的酒；对应对白结束后的同场空隙提示 |
| 试问卷帘人 | 向卷帘者试探问花，问语为改编补足；对应对白结束后的同场空隙提示 |
| 却道海棠依旧 | 对方判断没变，与问者在意的细节形成差异；对应对白结束后的同场空隙提示 |
| 知否，知否？ | 重复关切而非训斥；对应对白结束后的同场空隙提示 |
| 应是绿肥红瘦 | 推测叶繁花疏，不作亲眼证实；对应对白结束后的同场空隙提示 |

一次一条主要文字，不把全部原诗压在结尾。人物白话另设准确的对白字幕；旁白需要文字转录时，暂退原诗提示。不把“应是”截掉，也不让原诗字幕被误当成演员的实际台词。

## 改写边界

“稀稀落落”保留雨的稀疏，“睡得那么沉”保留睡眠深度，不把雨疏仅等同雨量小，也不把浓睡仅等同睡眠时间长。“你帮我看看”补足原文省略的问话；“我估计／应该”保留推断。叶繁花疏从场景开始已在，不拍成当场长叶落花。

原稿的独立“痕—檐水”“红—不足”等静物长覆盖不再作为必选镜头；手不再永久悬停，人物不再靠斜倚失神表达。镜头与动作服务一次平和的日常交谈，整首词的空间关系保持。
