# 验收清单

## 必须由人读稿／看片复核

| 维度 | 核验问题 | 不通过的典型情况 |
|---|---|---|
| 原意 | 每个完整诗句、否定、推断、对比都有承载吗？ | 余酒替代酒意；“应是”被演成证实；新增悲惨身世 |
| 对白 | 可在日常生活中自然说出口吗？ | “海棠依旧”“知否”仍当演员台词；舞台式抒情 |
| 镜头 | 人物开始对话时能看清说话者吗？ | 声音长期悬在花、酒盏、落瓣画面上 |
| 表演 | 动作有目的、正常速度、情绪适合场景吗？ | 慢移、垂眼看地、失神、叹气、郁闷式念词 |
| 声字 | 旁白只补必要信息，原诗与对白字幕分清吗？ | 三层长字幕堆叠；旁白压对白；原诗被改字 |
| 结构 | 保留已确认的全词同场结构吗？ | 夜雨、饮酒、入睡、醒来逐场重演；以静止冒充共时 |

先遮掉字幕听对白，检查其独立自然程度；再静音看动作和镜头，检查是否仍读得到平和关切；最后合看声画，不让字幕承担所有表达。仅审稿只能完成文字预审，不能声称已通过上述实际看片检查。

## 自动检查的用途

`validate_scene.py` 验证对象类型、非空字段、编号唯一性、语义单元覆盖、原诗提示、对白／镜头引用、主镜／空间锚、语义声明、表演标签、说话者镜头、旁白和对白分段。

有限字面模式只拦截明显古语、明显慢速／低落表演指令。它不会全面理解普通话、文学含义或剪辑效果；字段写了“normal”也不等于演员真的正常移动。物件镜头超过三秒产生待复核提醒，不自动判定所有三秒以上镜头都错误；含“slow”等技术调度字段不会误判为人物慢动作。

本模块不默认启动状态门控。复核发现问题就列明并改稿；无法实际验证的项目标为未验证，不能把静态脚本测试说成视频生成或宿主安装成功。
