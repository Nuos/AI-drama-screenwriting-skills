# 验收清单 · 1.1.0

| 维度 | 核验问题 | 必须退回的情况 |
|---|---|---|
| 整体语境 | 人物实际聊到共同活动、关系或既有经历了吗？ | 只把原词换成六句释义 |
| 连贯对白 | 主语、对象、回应关系和当前目的是否清楚？ | 无来由追问、代词悬空、答非所问 |
| 全室外 | 每个镜头的角色与摄影机都在露天吗？ | 主场移外而反打留屋内；屋舍承载行动 |
| 想象 | 观众能具体看见／听见什么？ | 只写“空灵诗意”；特效抢掉人物或暗变闪回 |
| 旁白 | 新增了什么当前画面无法给的信息？ | 猜角色意图、翻译词义、分析句式或复述动作 |
| 人物镜头 | 开口就直拍说话者，肩颈和口型可读吗？ | 完整对白长期由花、杯或特效覆盖 |
| 表演 | 正常行动，平和、明确、合场景吗？ | 慢移、垂头看地、叹气、郁闷式表演 |
| 语义 | 稀疏、深睡、酒意、推断仍有承担吗？ | 在没有授权说明时改变关键关系 |
| 声字 | 人声清楚，诗句完整，字幕分轨吗？ | 旁白压对白，字幕强迫停顿或整段堆到结尾 |
| 结构 | 全词同场，当前聊天自然展开吗？ | 按夜雨→饮酒→睡→醒→问花演一遍 |

完整听读对白，独立查看室外机位表，再检查声画合成设计。文字预审只证明稿件已复核，不能冒充实际听音、看样片或宿主加载。

自动检查覆盖字段、类型、引用、话轮、室外标记、明确室内动作、旁白禁用字面结构、背景依据和视听效果登记。文本语义与声画质量仍需人工。自动规则不能识别所有同义改写；写了 `outdoor` 也不能证明生成画面真的在室外。

回归用旧版固定样本仅证明协议1.0兼容，不能作为当前创作模板。新案例、默认模板与主规则均采用1.1；旧稿不通过新要求不算兼容测试失败。
